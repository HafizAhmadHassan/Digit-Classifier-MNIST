# MNIST Digit Classifier (from scratch)
*Created: 2019-02-08*

A handwritten digit classifier built **entirely from scratch** in **MATLAB**.

## Overview

Implements an artificial neural network with a perceptron layer, sigmoid activation, and MNIST data loading. The network is trained and tested on the MNIST handwritten digit dataset without relying on high-level deep-learning frameworks.

## Features

- Neural network implemented from scratch
- Perceptron layer with sigmoid activation
- MNIST data loading and preprocessing
- Training and evaluation on MNIST

## Tech Stack

MATLAB, artificial neural networks, image classification.

Completed course / learning project.
